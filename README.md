## Makedown 语法

 	Markdown是文本修饰语言， 使用修饰符结合正文， 让正文有一个美观的效果， 只需要学习常用的效果修饰符即可,  大多数情况下， 修饰符与正文之间， 使用空格分隔， 下面列出常用修饰符，  预留作业， 将github图， 变为Markedown的学习文档！



### 1.标题修饰符

​    #空格标题， 是标题修饰符， 表示一级标题， #越多级别越低， 一级标题字体最大，



# 一级标题

## 二级标题

### 三级标题

#### 四级标题



### 2.正文以及文本修饰样式

​    直接在文档中编辑， 都是正文内容， 在某些平台下需要使用\<br\>为换行符，编辑器enter换行，但是某些环境必须使用br

##### 斜体修饰

 使用\*斜体文本\*包含一段文字， 该文字为斜体效果,  \*\*粗体样式\*\*   \*\*\*粗斜体\*\*\*   \`凸显关键字\`   \~\~删除线效果\~\~

 *斜体样式*

**粗体样式**

***粗斜体***

在一段正文中`关键字`重点显示

~~有删除线效果的正文~~



### 3.列表 （无序列表/有序列表）， 列表可以混合使用

  列表用来做内容的指引目录， * 内容，  这表示1级列表   1.  内容 表示1级有序列表,  子级不用与父级对其

* 物理学
  * 粒子物理
  * 原子核物理
* 计算机科学
  * 套接字socket
    * bind
    * listen
* 哲学

### 4. 引用

 使用> 关键字， 这个称为一级引用,  一般编辑一段内容， 引用外部素材

> 一级引用
>
> > 二级引用
> >
> > > 三级引用
> > >
> > > > 四级引用



### 5.超链接标签

\[超链接标题\]\(网站的url地址  "悬停标题"\),  文档中加入超链接， 基本样式

[Github](https://github.com  "孙子点我")



### 6. 插入图表（本地图片/网图）

\!\[图片标题\]\(图片地址  “悬停标题”\), 文档中加入图片 ， 基本样式

![截图](https://i.imgs.ovh/2026/09/13/66e7a4bff43c8fe415a2cb03160355cb.png "儿子点我")
